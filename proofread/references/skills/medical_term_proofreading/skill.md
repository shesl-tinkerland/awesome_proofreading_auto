# 医学术语校对技能 (Medical Terminology Proofreading Skill)

## 技能描述

专门用于校对医学书籍中的专业术语使用规范性，包括解剖学术语、疾病名称、药物名称、检查项目、计量单位等各类医学术语的标准化检查。

## 校对依据

- **国家卫健委《常用临床医学名词(2023版)》** — 42,217条权威术语（最高优先级，见下方"术语规范性检查"）
- 《医学名词》全国科学技术名词审定委员会
- 《中华人民共和国药典》
- 《国际疾病分类第10次修订本》（ICD-10）
- MeSH（医学主题词表）
- 《中医药名词》

## 校对项目

### 0. NHC术语规范性检查 ⭐ 最高优先级

**权威来源**：`knowledge_base/nhc_clinical_terms.json`（42,217条术语，来自国家卫健委《常用临床医学名词(2023版)》）

**查询方式**（对文档中出现的医学术语，逐个执行以下校验）：
```bash
# 在项目根目录下运行
python3 knowledge_base/lookup_term.py <术语名>      # 精确查询
python3 knowledge_base/lookup_term.py <术语名> --all # 含模糊匹配
```

**校验规则**：

- [ ] **别名→规范名**：文档中使用的术语如果是 NHC 记录的别名（又称），应建议改为规范名
  - 示例：文档写"Argyll-Robertson瞳孔" → NHC规范名"阿·罗瞳孔"，别名含"Argyll-Robertson瞳孔"
  - 示例：文档写"褥疮" → NHC规范名"压疮"，别名含"褥疮"
- [ ] **术语不在库中**：文档中的疾病名/症状名/手术名/检查名不在 NHC 术语库中时，标记为需人工核实
  - 注意：NHC 仅收录临床术语（疾病、症状、手术、检查），不包含基础科学术语（如分子名、基因名），基础科学术语不触发此规则
- [ ] **中英对照校验**：NHC 记录的中英对照关系与文档中的中英翻译不一致时，标记为 major
- [ ] **科室归属校验**：术语在文档中归属的科室与 NHC 记录的科室不一致时，标记为 minor

**输出格式**（在原有 JSON 格式中新增字段）：
```json
{
  "term": "褥疮",
  "is_standard": false,
  "standard_form": "压疮",
  "nhc_match": {
    "matched_as": "alias",
    "standard_name": "压疮",
    "english": "pressure ulcer",
    "chapter": "康复医学科"
  }
}
```

### 1. 解剖学术语检查
- [ ] 解剖部位名称规范
- [ ] 方位术语准确（上下前后左右内外等）
- [ ] 结构层次术语正确
- [ ] 解剖姿势标准
- [ ] 缩写规范（TA、ICD等）
- [ ] **解剖学精确性检查** ⭐ 新增
  - 涉及电生理描述时，应精确到细胞层级而非器官层级
  - 错误示例："心脏的电活动" → 正确："心肌细胞的电活动"
  - 错误示例："肾脏的滤过功能" → 正确："肾小球的滤过功能"
  - 错误示例："肺的气体交换" → 正确："肺泡的气体交换"
  - 规则：功能描述应精确到执行该功能的最小解剖学单位（组织/细胞层级）

### 2. 疾病名称检查
- [ ] 疾病名称符合ICD-10标准
- [ ] 中文疾病名称规范
- [ ] 综合征名称正确
- [ ] 并发症表述规范
- [ ] 疾病分类正确

### 3. 药物名称检查
- [ ] 通用名使用（INN）
- [ ] 商品名标注
- [ ] 化学名准确
- [ ] 剂型名称规范
- [ ] 药理学分类正确

### 4. 检查项目名称检查
- [ ] 实验室检查项目名称规范
- [ ] 影像学检查名称正确
- [ ] 功能检查名称标准
- [ ] 病理检查名称规范
- [ ] 检查方法描述准确

### 5. 诊断相关术语检查
- [ ] 诊断术语规范
- [ ] 鉴别诊断术语正确
- [ ] 临床分期标准
- [ ] 严重程度分级
- [ ] 诊断标准引用正确

### 6. 治疗相关术语检查
- [ ] 治疗方法名称规范
- [ ] 手术名称标准
- [ ] 治疗方案术语准确
- [ ] 剂量单位规范
- [ ] 用法术语标准

### 7. 症状体征术语检查
- [ ] 症状描述规范
- [ ] 体征名称准确
- [ ] 疼痛描述标准
- [ ] 功能状态术语规范
- [ ] 评分量表正确

### 8. 统计学术语检查
- [ ] 统计学指标名称规范
- [ ] 统计学术语标准
- [ ] P值表述规范
- [ ] 置信区间描述正确
- [ ] 统计方法名称准确

### 9. 计量单位检查
- [ ] 使用法定计量单位
- [ ] 单位符号符合SI标准
- [ ] 避免使用非标准单位
- [ ] 单位换算正确
- [ ] 组合单位规范

### 10. 缩写规范检查
- [ ] 首次出现有全称
- [ ] 缩写符合国际规范
- [ ] 大小写正确
- [ ] 全书缩写统一
- [ ] 避免生僻缩写

### 11. 术语语境准确性检查 ⭐ 核心增强
- [ ] **缩写与其上下文含义一致**
  - 例：ESR上下文是否指"红细胞沉降率"而非"exchangeable sodium ratio"
  - 例：ACEI在心血管章节是否为"血管紧张素转换酶抑制剂"
- [ ] **化验值与临床描述匹配**
  - 例：WBC升高时，描述是否为"白细胞升高"
  - 例：Hb降低时，描述是否为"贫血"
- [ ] **诊断与症状对应**
  - 例：描述"高血压"时，血压数值是否确实升高
  - 例：描述"发热"时，体温数值是否超过正常范围
- [ ] **检查项目与临床目的相关**
  - 例：感染性疾病是否检查了炎症指标（CRP/PCT）
  - 例：心脏病是否检查了心肌酶/BNP
- [ ] **药物使用与诊断适应症匹配**
  - 例：诊断为"感染"时，是否使用了抗生素
  - 例：诊断为"心衰"时，是否使用了利尿剂/ACEI等
- [ ] **解剖学术语与手术/检查对应**
  - 例：描述"冠脉造影"时，是否涉及冠状动脉
  - 例：描述"胃镜"时，是否涉及胃部结构
- [ ] **体征描述与术语一致**
  - 例："心脏杂音"与超声发现的瓣膜问题对应
  - 例："肺部啰音"与肺部感染诊断对应
- [ ] **影像学描述与临床诊断一致**
  - 例：CT描述的病灶位置与临床诊断的解剖部位一致
  - 例：超声测量值与描述的严重程度一致

## 优先级说明（新增语境相关）

### critical（严重）
- **核心术语翻译错误**：如ESR翻译为"exchangeable sodium ratio"
- **诊断与化验严重不符**：可能误导临床判断
- **药物与诊断严重不匹配**：可能导致错误治疗

### major（重要）
- **缩写与上下文不符**：影响理解但可能通过上下文推断
- **化验值与描述轻微不一致**：需要核实
- **检查项目与目的不匹配**：可能遗漏重要检查

### minor（轻微）
- **非核心术语的小问题**：不影响整体理解
- **描述精确性不够**：但不影响准确性

## 常见术语问题

### A. 基础术语规范问题
| 问题类型 | 示例 | 规范写法 |
|---------|------|---------|
| 非规范简称 | "甲流" | "甲型流感" |
| 英文未译 | "MRI检查" | "磁共振成像（MRI）检查" |
| 缩写未说明 | "使用ACEI" | "使用血管紧张素转换酶抑制剂（ACEI）" |
| 术语不统一 | "肿瘤"/"癌肿"混用 | 统一使用"肿瘤" |
| 旧名称 | "红血球" | "红细胞" |
| 商品名替代通用名 | "泰诺" | "对乙酰氨基酚"（可加注商品名） |

### B. 术语语境准确性问题 ⭐ 新增
| 问题类型 | 示例 | 修正建议 |
|---------|------|---------|
| 英文缩写翻译错误 | ESR被注为"exchangeable sodium ratio" | 应为"erythrocyte sedimentation rate（红细胞沉降率）" |
| 缩写与上下文不符 | 文中描述凝血功能，但出现"ESR" | ESR是炎症指标，凝血功能应检查PT/APTT |
| 化验值与描述矛盾 | 描述"贫血"，Hb 130g/L（正常） | 核实Hb值或诊断 |
| 诊断与化验值不符 | 诊断"严重感染"，CRP 5mg/L（正常） | 检查诊断准确性或化验值 |
| 药物与诊断不匹配 | 诊断"过敏性血管炎"，使用抗生素 | 抗生素不治疗过敏，应使用激素/免疫抑制剂 |
| 检查项目与目的不符 | 怀疑"感染"，只做肝肾功能 | 应做血常规、CRP、PCT、血培养等 |
| 解剖术语与手术不符 | "胃镜检查"描述结肠 | 胃镜只检查食管、胃、十二指肠 |
| 影像描述与诊断矛盾 | CT报告"肺部正常"，诊断"肺炎" | 检查影像或诊断准确性 |
| 体征与术语不一致 | 描述"心脏杂音"，超声报告瓣膜正常 | 核实体征或超声结果 |
| 严重程度描述与数值不符 | "重度贫血"，Hb 100g/L（轻度） | 调整描述或核实数值 |

## 质量标准

- **优秀**：术语100%规范，缩写说明完整
- **良好**：主要术语规范，个别问题
- **合格**：核心术语正确，部分不规范
- **不合格**：多处术语错误或严重不规范

## 不检查范围

以下检查由其他技能负责，本技能不涉及：
- **术语跨章节一致性**：由 consistency_proofreading 负责
- **翻译质量**：由 translation_proofreading 负责
- **语言语法和标点**：由 language_proofreading 负责
- **参考文献格式**：由 reference_proofreading 负责
- **临床诊断逻辑**：由 clinical_logic_proofreading 负责

## 注意事项

1. 医学术语的准确性直接关系到医疗安全
2. 优先使用全国科学技术名词审定委员会公布的规范术语
3. 新兴术语需查阅权威文献确认
4. 注意区分中英文医学术语的表达差异
5. 保留必要的英文原文便于读者对照
6. 药物名称以通用名为主，商品名首次出现需说明
7. 缩写使用应遵循首次出现注明的原则
8. 全书术语必须保持一致

## 输出要求

### 简洁原则

为避免冗长输出，请按以下原则：

1. **简单格式错误**（单位符号、缩写格式等）：
   - description：5字以内
   - suggestion：直接修改
   - reason：可省略

2. **术语不规范**：
   - description：10字以内
   - suggestion：给出规范术语
   - reason：简要说明（不超过30字）

3. **译名错误、漏译**：
   - description：简要说明
   - suggestion：给出正确术语或译文
   - reason：简洁解释（可选）

### 避免冗余

- ❌ 错误："建议将XX修改为YY"
- ✅ 正确：current写"XX"，suggestion写"YY"
- ❌ 错误：description中重复完整句子
- ✅ 正确：description简洁描述
- ❌ 错误：reason过长解释
- ✅ 正确：reason简洁或省略
