## 1. 缩写使用规范

### 1.1 首次定义检查
- [ ] 逐一检索文中所有英文缩写，核实首次出现处是否按"中文全称（英文全称，英文缩写）"格式标注
- [ ] 确认缩写定义仅在全书中第一次出现时给出，后续重复出现不再重复定义
- [ ] 核实章首或节首若以缩写开头，是否在本章/节首次正文段落中补全定义

### 1.2 缩写一致性检查
- [ ] 提取全书中所有缩写，按字母排序汇总，检查同一概念是否始终使用同一缩写形式（如 ACEI / ACE-I / ACE抑制剂 不应混用）
- [ ] 检查缩写大小写是否全书统一（如 DNA / dna / Dna）
- [ ] 检查缩写是否使用了符合专业习惯的公认形式

## 2. 术语一致性

### 2.1 医学术语统一
- [ ] 提取全书医学术语，按术语归类，检查同一术语在不同章节是否使用相同中文表述
- [ ] 核对疾病名称是否全书使用同一命名（如"冠心病"与"冠状动脉粥样硬化性心脏病"不宜混用，应选定一种并在首次出现时注明别名）
- [ ] 核对解剖学术语是否全书命名统一（如"十二指肠"与"十二指肠部"不混用）
- [ ] 核对手术/操作名称是否全书一致

### 2.2 翻译术语统一
- [ ] 提取所有英文术语的中文翻译，检查同一英文术语是否全书使用同一译名
- [ ] 核对译名是否符合全国科学技术名词审定委员会公布的《医学名词》标准
- [ ] 如存在约定俗成的多种译名，确认全书选定一种并在前言或术语表中说明

## 3. 人名翻译规范

### 3.1 外国人名
- [ ] 检查外国人名首次出现是否注明原文（如"希波克拉底（Hippocrates）"）
- [ ] 核对同一外国人名全书音译是否一致（如"奥斯勒"不出现"欧斯勒"）
- [ ] 确认人名缩写格式统一（如"Watson J"或"Watson J."全书统一）

### 3.2 中国人名
- [ ] 检查中国人名是否使用汉字全称，不随意用英文缩写替代
- [ ] 核对同一人物在全书中称谓一致（不出现"张仲景"与"张机"混用而无说明）

## 4. 机构名称规范

### 4.1 国内机构
- [ ] 检查机构名称首次出现是否使用全称，后续是否统一使用简称
- [ ] 核对同一机构简称形式全书一致（如"国家卫健委"不混用"卫健委""国家卫生计生委"）

### 4.2 国际机构
- [ ] 检查国际组织名称是否使用标准译名（如 WHO 统一译为"世界卫生组织"）
- [ ] 核对国际机构名称首次出现是否按"中文译名（英文全称，英文缩写）"格式标注

## 5. 药物名称规范

### 5.1 通用名与商品名
- [ ] 提取全书药物名称，确认是否优先使用通用名（如"阿司匹林"而非"拜阿司匹灵"）
- [ ] 如需使用商品名，确认是否在首次出现时标注"通用名（商品名）"格式
- [ ] 核对同一药物全书使用一致的名称形式

### 5.2 药物英文名称
- [ ] 检查药物英文名称拼写全书一致（如"Metformin"不出现"metformin""Met formin"等变体）
- [ ] 核对药物英文缩写是否全书统一（如"5-FU"不混用"5FU""5-Fu"）

## 6. 量词单位规范

### 6.1 量词统一
- [ ] 提取同类对象的量词使用情况，确认全书一致（如患者统一用"例"而非"例""名"混用）
- [ ] 检查实验/研究对象的量词是否统一（如"只"用于动物，"例"用于患者）
- [ ] 确认计数表述统一（如"共纳入50例"与"共计50例"不随意混用）

### 6.2 单位符号
- [ ] 检查计量单位符号是否全书统一且符合国家标准（如 mg 不出现 Mg、mG）
- [ ] 核对单位符号与中文单位名称不混用（如"mg"与"毫克"不混用）
- [ ] 检查血压单位格式统一（如"120/80 mmHg"，全书一致）

## 7. 全文交叉核对

### 7.1 目录与正文
- [ ] 核对目录中的术语、缩写、名称与正文中的实际表述一致
- [ ] 核对章节标题中的关键术语与正文中的术语使用一致

### 7.2 正文前后章节
- [ ] 按章节顺序通读，标记术语首次定义位置，确认后续使用与定义一致
- [ ] 重点核查跨章节引用的术语、缩写、人名、药名是否前后一致

### 7.3 正文与附录/索引
- [ ] 核对附录术语表中的术语与正文实际使用一致
- [ ] 核对索引中收录的术语名与正文中的写法一致

## 常见术语问题速查

### 缩写相关
- [ ] 首次使用未定义 → 补充"中文全称（英文全称，英文缩写）"
- [ ] 同一概念多种缩写 → 全书统一使用一种表述
- [ ] 缩写不符合专业习惯 → 改用公认形式

### 术语翻译不统一
- [ ] 同一术语多种译法 → 根据出版时间和专业规范统一
- [ ] 人名翻译不统一 → 首次出现注明原名，后续统一使用译名或原名

### 药物名称不统一
- [ ] 通用名与商品名混用 → 优先使用通用名，商品名需注明

### 量词使用不统一
- [ ] 同一类型对象量词不一致 → 全书统一使用"例"

### 单位符号不统一
- [ ] 同一单位多种表示（如 mg/Mg/mG） → 严格使用标准单位符号

## 问题严重等级速查

| 等级 | 适用情形 |
|------|----------|
| **critical** | 核心术语翻译错误导致理解偏差；关键数据单位不一致（如剂量单位 mg 与 μg 混用） |
| **major** | 缩写首次使用未定义；同一术语多种表述；人名/机构名翻译不统一；药物通用名与商品名混用 |
| **minor** | 非核心术语表述细微差异；量词使用不够规范但不影响理解；单位符号大小写偶发不一致 |

## 输出要求
- `description` 字段不超过 15 字，精炼概括问题

- 每个 issue 必须包含 `term_info`（含首次出现位置、当前出现位置、所有变体列表），便于定位和批量修正
