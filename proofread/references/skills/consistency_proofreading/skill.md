# 术语一致性校对技能

## 技能描述

本技能用于检查医学书籍中的术语一致性，确保同一概念在全书中使用统一的表述。通过分析全文，识别术语使用的不一致问题，包括缩写未定义、翻译不统一、表述差异等。

**检查范围**：
- 医学术语名词（中英文）
- 人名（翻译名、原名）
- 机构名称
- 英文术语、英文缩写
- 量词、单位名称
- 药物名称（通用名 vs 商品名）

## 校对依据

- 《医学名词》全国科学技术名词审定委员会
- 《医学编辑手册》
- 专业术语翻译规范
- GB/T 7714-2025 信息与文献 参考文献著录规则
- CY/T 35-2001 科技出版物编排规则

## 校对项目

### 缩写使用规范
- [ ] 缩写首次出现时是否标注全称（格式：中文全称（英文全称，英文缩写））
- [ ] 同一缩写全书表述一致
- [ ] 缩写使用是否符合专业习惯

### 术语一致性
- [ ] 同一医学术语在不同章节表述一致
- [ ] 专业翻译术语全书统一
- [ ] 疾病名称诊断标准统一
- [ ] 解剖学术语命名统一

### 人名翻译规范
- [ ] 人名翻译前后一致（音译规则统一）
- [ ] 外国人名首次出现注明原名
- [ ] 中国人名使用规范（不随意使用英文缩写）

### 机构名称规范
- [ ] 机构名称翻译前后一致
- [ ] 机构简称全书统一
- [ ] 国际组织名称使用标准译名

### 药物名称规范
- [ ] 药物名称使用全书一致
- [ ] 通用名与商品名使用规范
- [ ] 药品英文名称统一

### 量词单位规范
- [ ] 量词使用规范统一（例、名、种、类、项等）
- [ ] 单位名称统一（mg、mmHg、pg/mL、℃等）
- [ ] 单位符号使用符合国家标准

## 常见术语问题

### 缩写相关问题
1. **首次使用未定义**：
   - 问题：直接使用缩写，未说明全称
   - 示例："ACEI是常用的降压药物" → "血管紧张素转换酶抑制剂（angiotensin converting enzyme inhibitors，ACEI）是常用的降压药物"

2. **同一概念多种缩写**：
   - 问题：ACEI、ACE-I、ACE抑制剂混用
   - 建议：全书统一使用一种表述

### 术语翻译不统一
1. **同一术语多种译法**：
   - 问题：新冠肺炎、COVID-19、新型冠状病毒肺炎混用
   - 建议：根据出版时间和专业规范统一

2. **人名翻译不统一**：
   - 问题：同一人名出现"史密斯"、"Smith"等不同表述
   - 建议：首次出现注明原名，后续统一使用译名或原名

### 药物名称不统一
1. **通用名与商品名混用**：
   - 问题：阿司匹林、拜阿司匹林混用
   - 建议：优先使用通用名，商品名需注明

### 量词使用不统一
1. **同一类型对象量词不一致**：
   - 问题：患者3例、病人5名混用
   - 建议：全书统一使用"例"

### 单位符号不统一
1. **同一单位多种表示**：
   - 问题：mg、Mg、mG混用
   - 建议：严格使用标准单位符号

## 输出格式

输出为 JSON 对象，顶层为 `{"issues": [...]}` 数组。每个 issue 包含以下字段：

```json
{
  "issues": [
    {
      "category": "consistency",
      "severity": "major",
      "location": "P5",
      "current": "ACEI",
      "suggested": "血管紧张素转换酶抑制剂（angiotensin converting enzyme inhibitors，ACEI）",
      "description": "缩写未定义",
      "reason": "专业缩写首次出现时应标注全称，便于读者理解"
    }
  ]
}
```

字段说明：
- `category`：固定为 `"consistency"`
- `severity`：`"critical"` | `"major"` | `"minor"`
- `location`：错误所在段落，格式为 `P{段落编号}`（如 `P5`、`P161`）或段落范围（如 `P303-306`）
- `current`：原文中的问题文本
- `suggested`：建议修改后的文本
- `description`：问题简述（5-15字）
- `reason`：修改理由

## 优先级说明

### critical（严重）
- 核心术语翻译错误，可能导致理解偏差
- 关键数据单位不一致

### major（重要）
- 缩写首次使用未定义
- 同一术语多种表述
- 人名、机构名翻译不统一
- 药物名称使用混乱

### minor（轻微）
- 非核心术语表述差异
- 量词使用不够规范

## 不检查范围

以下检查由其他技能负责，本技能不涉及：
- **术语本身是否为NHC规范名**：由 medical_term_proofreading 负责
- **语言语法和标点**：由 language_proofreading 负责
- **翻译准确性**：由 translation_proofreading 负责
- **参考文献格式**：由 reference_proofreading 负责
