# 参考文献校对技能 (Reference Proofreading Skill)

## 技能描述

专门用于校对医学书籍中的参考文献，确保参考文献符合GB/T 7714-2025国家标准，检查文献的完整性、准确性和格式规范性。

## 校对依据

- **GB/T 7714-2025** 《信息与文献 参考文献著录规则》
- **ICMJE推荐规范** 医学期刊编辑国际委员会标准

## 校对项目

### 1. 文献编号检查
- [ ] 编号连续无缺失
- [ ] 编号格式正确（[1]、[2]...）
- [ ] 正文引用与文献编号对应
- [ ] 同一文献多次引用编号一致

### 2. 作者信息检查
- [ ] 作者姓名格式正确
- [ ] 作者数量符合要求（列出前3位，后加"等"或"et al"）
- [ ] 外文作者姓前名后
- [ ] 作者之间分隔符正确（逗号）
- [ ] 译者、编者标注正确

### 3. 文献题名检查
- [ ] 文献题名完整
- [ ] 期刊名使用规范缩写
- [ ] 书名、报告名完整
- [ ] 副标题处理正确
- [ ] 英文题名大小写规范

### 4. 期刊信息检查
- [ ] 期刊名缩写符合ISO 4标准
- [ ] 出版年份正确
- [ ] 卷号正确
- [ ] 期号正确（如有）
- [ ] 页码范围完整
- [ ] 卷期标注格式正确

### 5. 出版信息检查（图书）
- [ ] 出版地准确
- [ ] 出版社名称完整
- [ ] 出版年份正确
- [ ] 版次标注（第2版及以上）
- [ ] ISBN号码（如有）

### 6. 电子文献检查
- [ ] DOI链接完整且有效
- [ ] URL链接可访问
- [ ] 访问日期标注（如需要）
- [ ] 数据库来源标注
- [ ] 文献类型标识正确（[EB/OL]、[J/OL]等）

### 7. 格式规范检查
- [ ] 标点符号使用正确
- [ ] 空格位置正确
- [ ] 斜体使用正确（期刊名、卷号）
- [ ] 字体大小一致
- [ ] 缩进格式正确

### 8. 特殊类型文献
- [ ] **期刊文章**：作者. 题名[J]. 期刊名, 年, 卷(期): 起止页码.
- [ ] **图书**：作者. 书名[M]. 版次(第1版不著录). 出版地: 出版社, 出版年: 起止页码.
- [ ] **学位论文**：作者. 题名[D]. 保存地: 保存单位, 年份.
- [ ] **会议论文**：作者. 题名[C]//会议录题名. 出版地: 出版社, 出版年: 起止页码.
- [ ] **专利**：专利所有者. 题名: 专利号[P]. 公告日期.
- [ ] **技术标准**：标准编号 标准名称[S].
- [ ] **网络资源**：作者. 题名[EB/OL]. (更新日期)[引用日期]. URL.

### 9. 一致性检查
- [ ] 正文中引用的文献都在参考文献列表中
- [ ] 参考文献列表中的文献在正文中都有引用
- [ ] 同一文献在正文和列表中的信息一致
- [ ] 同一作者姓名在所有文献中格式一致
- [ ] 同一期刊在所有文献中缩写一致

### 10. 数据验证
- [ ] 关键文献已核对原始来源
- [ ] DOI链接已测试有效性
- [ ] 高被引文献优先验证
- [ ] 近年文献（5年内）优先验证

## GB/T 7714-2025 主要变化

1. **电子资源著录更详细**：增加了访问日期、获取和访问路径等要求
2. **DOI著录规范化**：统一了DOI的著录格式
3. **作者著录规则更新**：明确了超过3位作者的著录方法
4. **标点符号使用调整**：部分标点使用规则有变化

## 输出格式

```json
{
  "issues": [
    {
      "category": "问题类别",
      "severity": "critical/major/minor",
      "location": "P{段落编号}",
      "description": "简短问题描述",
      "current": "当前文本",
      "suggested": "建议修改",
      "reason": "修改依据",
      "reference_id": "[1]",
      "field": "问题字段"
    }
  ]
}
```

允许在每个 issue 中附加 `reference_id`、`field` 等本技能专有字段，但顶层必须为 `issues` 数组。

## 常见问题类型

| 问题类别 | 严重程度 | 示例 |
|---------|---------|------|
| 信息缺失 | 严重 | 缺少作者、年份、页码等 |
| 信息错误 | 严重 | 作者名拼写错误、年份错误 |
| 格式错误 | 一般 | 标点错误、缩写不规范 |
| 期刊缩写错误 | 一般 | 未使用ISO 4标准缩写 |
| DOI无效 | 轻微 | 链接失效或格式错误 |

## 质量标准

- **无问题**：文献完全符合GB/T 7714-2025
- **轻微问题**：标点、空格等细节问题
- **一般问题**：格式不规范但信息完整
- **严重问题**：信息缺失、错误或格式严重不符

## 不检查范围

以下检查由其他技能负责，本技能不涉及：
- **术语标准性**：由 medical_term_proofreading 负责
- **语言语法和标点**：由 language_proofreading 负责
- **翻译质量**：由 translation_proofreading 负责

## 正文引用标记处理

正文中出现的 `<sup>[N]</sup>` 标记是原文中的上角标引用编号，已由提取脚本从PDF识别并标准化。
- **不要**对 `<sup>` 包裹的内容标记括号类型错误（全角/半角）
- **不要**对 `<sup>` 内容标记位置、间距或格式问题
- 正文引用编号与文献列表的对应关系属于本技能检查范围

## 注意事项

1. 医学文献的准确性直接影响学术质量
2. 优先验证核心文献和高引用文献
3. 注意区分不同文献类型的著录格式
4. 英文期刊名应使用标准缩写
5. DOI是验证文献准确性的重要工具
6. 建议使用专业文献管理软件（如EndNote、NoteExpress）

## 参考工具

- **NLM Catalog**：查询期刊标准缩写
- **中国知网**：查询中文文献
- **万方数据**：查询中文文献
