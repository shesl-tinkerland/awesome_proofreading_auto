## 1. 诊断一致性检查

### 1.1 主诉与诊断
- [ ] 主诉与最终诊断符合
- [ ] 主诉所描述的症状/体征能支持最终诊断结论

### 1.2 症状与诊断匹配
- [ ] 描述的症状符合诊断的典型表现
- [ ] 症状持续时间与疾病病程一致

### 1.3 体征与诊断支持
- [ ] 体格检查发现能支持诊断结论
- [ ] 阳性体征与诊断具有对应关系

### 1.4 化验结果与诊断一致
- [ ] 实验室检查结果符合诊断预期
- [ ] 关键阳性/阴性指标已列出

### 1.5 影像学与诊断对应
- [ ] 影像学表现支持诊断结论
- [ ] 影像学描述与诊断无矛盾

### 1.6 鉴别诊断充分
- [ ] 已排除必要的鉴别诊断
- [ ] 鉴别诊断的排除依据合理

### 1.7 诊断标准完整
- [ ] 诊断符合相应诊断标准
- [ ] 必要的诊断依据条目已逐项列出

## 2. 检查结果合理性检查

### 2.1 化验值范围合理
- [ ] 化验值在医学可能范围内
- [ ] 无超出生理极限的不合理数值

### 2.2 多项化验结果一致
- [ ] WBC升高时，中性粒细胞百分比也升高
- [ ] 贫血时，Hb、RBC、HCT同步变化
- [ ] 肝损伤时，ALT/AST同步变化
- [ ] 肾损伤时，Cr和BUN同步变化

### 2.3 化验值与临床状态匹配
- [ ] 严重感染时，CRP和PCT升高
- [ ] 肝功能异常时，ALT/AST升高
- [ ] 心肌损伤时，cTnI/cTnT/CK-MB升高

### 2.4 影像学与临床一致性
- [ ] 影像描述与临床症状一致
- [ ] 病理结果与临床表现符合

## 常见逻辑问题速查

### 诊断与化验不符
- [ ] 感染诊断但炎症指标正常
- [ ] 贫血诊断但血常规正常
- [ ] 肝病诊断但肝功能正常

### 症状与体征不符
- [ ] 发热描述但体温记录正常
- [ ] 呼吸困难描述但肺部听诊正常
- [ ] 水肿描述但查体无阳性发现

### 治疗与诊断不符
- [ ] 抗生素用于非感染性疾病
- [ ] 药物剂量超出常规范围
- [ ] 治疗方案与诊断级别不匹配

### 时间逻辑问题
- [ ] 药物起效时间过快或过慢
- [ ] 症状发展速度不合理
- [ ] 检查与诊断时间倒置

### 化验结果内部矛盾
- [ ] WBC升高但中性粒细胞正常
- [ ] 贫血但RBC计数正常
- [ ] 肾功能异常但电解质正常
