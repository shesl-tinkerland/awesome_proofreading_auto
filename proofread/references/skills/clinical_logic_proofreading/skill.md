# 临床逻辑校对技能 (Clinical Logic Proofreading Skill)

## 技能描述

专门用于检查医学书籍中的临床逻辑一致性，包括诊断与症状的对应关系、检查结果的合理性、治疗方案的逻辑性等医学专业性判断。这是医学编辑最核心的能力之一，需要具备临床医学专业知识。

**核心目标**：确保医学内容的科学性、逻辑性、准确性，避免误导读者或临床实践。

## 校对依据

- 各学科临床指南和专家共识
- 循证医学证据
- 临床路径标准
- 病历书写规范
- 诊断学、内科学、外科学等教材
- WHO临床诊疗指南

## 校对项目

### 1. 诊断一致性检查
- [ ] **主诉与诊断符合**：患者主诉是否能支持最终诊断
- [ ] **症状与诊断匹配**：描述的症状是否符合诊断的典型表现
- [ ] **体征与诊断支持**：体格检查发现是否能支持诊断
- [ ] **化验结果与诊断一致**：实验室检查结果是否符合诊断预期
- [ ] **影像学与诊断对应**：影像学表现是否支持诊断结论
- [ ] **鉴别诊断充分**：是否排除必要的鉴别诊断
- [ ] **诊断标准完整**：诊断是否符合相应的诊断标准

### 2. 检查结果合理性检查
- [ ] **化验值范围合理**：数值是否在可能的医学范围内
- [ ] **多项化验结果一致**：相关化验结果之间是否有逻辑冲突
  - 例：WBC升高时，中性粒细胞百分比也应相应升高
  - 例：贫血时，Hb应降低，但RBC和HCT也应相应变化
- [ ] **化验值与临床状态匹配**：
  - 例：严重感染时，CRP和PCT应升高
  - 例：肝功能异常时，ALT/AST应升高
- [ ] **影像学描述与临床一致**：影像表现是否符合临床症状
- [ ] **病理结果与临床符合**：病理诊断是否能解释临床表现

### 3. 治疗逻辑性检查
- [ ] **治疗方案与诊断对应**：治疗方案是否符合诊断
- [ ] **药物剂量合理**：剂量是否在治疗范围内
- [ ] **用药途径恰当**：给药途径是否合适（静脉/口服/肌注等）
- [ ] **治疗反应描述合理**：治疗后的反应是否符合药理学预期
- [ ] **治疗转归符合预期**：治疗效果是否符合疾病自然病程
- [ ] **用药时间合理**：用药频次、疗程是否合理
- [ ] **联合用药有依据**：药物联用是否有协同或必要性

### 4. 时间序列逻辑检查
- [ ] **事件时间顺序合理**：症状→就诊→检查→诊断→治疗的顺序
- [ ] **检查→诊断→治疗时间线**：时间间隔是否合理
- [ ] **症状发展时间符合病程**：症状进展速度是否符合疾病特点
- [ ] **治疗反应时间符合药理学**：起效时间是否合理
- [ ] **随访时间安排恰当**：复查时间是否符合临床常规

### 5. 病例叙述完整性检查
- [ ] **病例要素完整**：主诉、现病史、既往史、体格检查等
- [ ] **诊断依据充分**：是否有足够证据支持诊断
- [ ] **鉴别诊断合理**：是否考虑到主要鉴别诊断
- [ ] **治疗方案有依据**：治疗选择是否有循证依据

### 6. 因果链严谨性检查 ⭐ 新增
- [ ] **区分因果与相关**：科学写作中应区分因果推断与相关性描述
  - 错误示例："DTI的变化反映了WM完整性的丧失" → 正确："DTI的改变可反映WM完整性的丧失"（降级为相关性）
  - 错误示例："因为DTI异常" → 正确："其机制可能在于DTI异常"（更严谨的因果链表述）
- [ ] **因果表述用语规范**：
  - "反映了" → "可反映"（表示相关性，非确定性因果）
  - "因为" → "其机制在于" / "可能与...有关"（更严谨）
  - "导致" → "可能导致" / "与...相关"（当证据不够充分时）
  - "说明了" → "提示" / "表明"（表述应留有余地）
- [ ] **推断强度匹配证据等级**：循证等级越低，表述应越谨慎
  - 病例报告/专家意见 → "个案提示"、"有学者认为"
  - 观察性研究 → "可能与...有关"、"...可能是一个影响因素"
  - RCT/系统综述 → 可使用较强的因果表述
- [ ] **结局描述完整**：预后或转归是否交代

### 7. 医学数据交叉验证
- [ ] **化验单与病历描述一致**：化验数值与描述是否对应
- [ ] **影像学与报告一致**：影像描述与结论是否匹配
- [ ] **用药与医嘱一致**：用药记录与医嘱是否一致
- [ ] **病程记录与治疗一致**：病情变化与治疗调整是否对应

### 8. 专科特殊性检查
- [ ] **心血管系统**：心律与心电图、血压与药物、心脏超声与症状
- [ ] **呼吸系统**：血气分析与呼吸状态、胸片与症状、肺功能与诊断
- [ ] **消化系统**：肝功能与症状、内镜与诊断、影像与临床表现
- [ ] **内分泌系统**：激素水平与症状、血糖与用药、甲状腺功能与临床表现
- [ ] **神经系统**：症状与定位、影像与病灶、神经电生理与诊断

## 常见逻辑问题类型

### 1. 诊断与化验结果不符
| 问题描述 | 示例 | 修正建议 |
|---------|------|---------|
| 感染诊断但炎症指标正常 | 诊断为"严重感染"，但CRP、PCT正常 | 检查诊断是否成立，或化验值是否正确 |
| 贫血诊断但血常规正常 | 诊断"贫血"，Hb 130g/L | 核实诊断和化验值 |

### 2. 症状与体征不符
| 问题描述 | 示例 | 修正建议 |
|---------|------|---------|
| 发热但体温正常 | 描述"高热"，但体温36.5℃ | 核实体温记录或修正描述 |
| 呼吸困难但肺部正常 | "呼吸困难明显"，肺部听诊呼吸音清 | 补充体征或检查结果 |

### 3. 治疗与诊断不符
| 问题描述 | 示例 | 修正建议 |
|---------|------|---------|
| 抗生素治疗非感染性疾病 | 诊断为"过敏性血管炎"，使用抗生素 | 检查诊断或治疗方案 |
| 剂量不合理 | "万古霉素1.0g，每8小时1次" | 检查剂量（常规应为15-20mg/kg q8-12h） |

### 4. 时间逻辑混乱
| 问题描述 | 示例 | 修正建议 |
|---------|------|---------|
| 治疗起效时间过快 | "用药后立即起效" | 核实药代动力学 |
| 症状发展不合理 | "数小时内从正常到衰竭" | 检查病程描述 |

### 5. 化验结果内部矛盾
| 问题描述 | 示例 | 修正建议 |
|---------|------|---------|
| WBC升高但中性粒细胞正常 | WBC 15×10⁹/L，N% 45% | 检查分类计数是否准确 |
| 贫血但RBC正常 | Hb 80g/L，RBC 5.0×10¹²/L | 检查红细胞指数 |

## 优先级说明

### critical（严重）
- 诊断错误，可能误导临床实践
- 关键数据矛盾（如化验值与诊断不符）
- 治疗方案存在严重问题
- 时间逻辑严重混乱

### major（重要）
- 诊断依据不充分
- 化验结果轻微不合理
- 治疗方案需优化
- 部分数据不一致

### minor（轻微）
- 非关键数据的小问题
- 描述不够完整但不影响理解
- 细节上的小瑕疵

## 输出要求

### 简洁原则

1. **诊断不一致问题**：
   - description：5字以内
   - suggestion：明确指出不符之处
   - reason：简要说明医学依据（20字以内）

2. **化验结果问题**：
   - description：10字以内
   - suggestion：指出矛盾的具体项
   - reason：说明正常关系（15字以内）

3. **治疗逻辑问题**：
   - description：10字以内
   - suggestion：给出更合理的方案建议
   - reason：说明药理或指南依据

4. **时间序列问题**：
   - description：10字以内
   - suggestion：指出时间逻辑错误
   - reason：说明合理的时序关系

## 不检查范围

以下检查由其他技能负责，本技能不涉及：
- **术语标准性**：由 medical_term_proofreading 负责
- **语言语法和标点**：由 language_proofreading 负责
- **术语跨章节一致性**：由 consistency_proofreading 负责
- **表格数据准确性**：由 table_proofreading 负责
- **参考文献格式**：由 reference_proofreading 负责
- **翻译质量**：由 translation_proofreading 负责

## 注意事项

1. **临床逻辑校对需要专业知识**：不同专科有不同特点
2. **不确定时应标注**：而非猜测或忽略
3. **注意病历书写规范**：但更注重科学性和逻辑性
4. **区分个体差异与普遍规律**：不排除特殊情况
5. **循证依据优先**：以指南和循证医学为准
6. **保持客观中立**：不主观臆断
7. **关注患者安全**：可能误导临床的问题必须指出

## 质量标准

- **优秀**：无临床逻辑问题，内容科学严谨
- **良好**：偶有轻微问题但不影响整体
- **合格**：有一些问题但核心内容正确
- **不合格**：存在严重逻辑错误或科学性问题
