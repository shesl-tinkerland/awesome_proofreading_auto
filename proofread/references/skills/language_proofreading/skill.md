# 语言组织校对技能 (Language Proofreading Skill)

## 技能描述

专门用于校对医学书籍中文本的语言组织问题，包括语法、逻辑、标点、数字用法等基础语言规范。

## 校对依据

- 《现代汉语词典》
- 《科技书刊标准化用法》
- 《出版物上数字用法》（GB/T 15835-2011）
- 《标点符号用法》（GB/T 15834-2011）

## 校对项目

### 1. 语法检查
- [ ] 句子结构完整
- [ ] 主谓搭配恰当
- [ ] 动宾搭配恰当
- [ ] 定状补语位置正确
- [ ] 关联词使用正确
- [ ] 避免句式杂糅
- [ ] 避免成分残缺

### 2. 标点符号检查
- [ ] 句号使用正确
- [ ] 逗号使用正确
- [ ] 分号使用正确
- [ ] 冒号使用正确
- [ ] 问号、感叹号使用正确
- [ ] 引号使用正确
- [ ] 括号使用正确
- [ ] 破折号使用正确
- [ ] 省略号使用正确
- [ ] 书名号使用正确
- [ ] 间隔号使用正确
- [ ] 连接号使用正确

### 3. 数字用法检查
- [ ] 阿拉伯数字使用规范
- [ ] 汉字数字使用规范
- [ ] 数字与汉字混用得当
- [ ] 数值范围表示正确（~或—）
- [ ] 约数表示规范
- [ ] 分数表示规范
- [ ] 百分比表示规范
- [ ] 科学计数法规范
- [ ] 数字修约规范

### 4. 量和单位检查
- [ ] 使用法定计量单位
- [ ] 单位符号正确
- [ ] 单位名称正确
- [ ] 量符号正确
- [ ] 组合单位表示正确
- [ ] 避免使用已废弃单位

### 5. 文字表达检查
- [ ] 无错别字
- [ ] 无多字、漏字
- [ ] 用词准确
- [ ] 表达清晰
- [ ] 避免歧义
- [ ] 用词得体

### 6. 逻辑连贯性检查 ⭐ 核心增强
- [ ] **段落主题明确**
  - 段落是否有明确的中心思想
  - 段落内容是否围绕主题展开
  - 是否有跑题或偏离中心的内容
- [ ] **句子间逻辑清晰**
  - 句子之间是否有合理的逻辑关系
  - 因果、递进、转折等关系是否明确
  - 是否出现逻辑跳跃或断层
- [ ] **段落间过渡自然**
  - 段落之间是否有合理的过渡句
  - 是否有明显的断层或突兀转换
  - 段落顺序是否符合逻辑（时间、空间、重要性等）
- [ ] **前后内容呼应**
  - 前文提到的问题，后文是否有回应
  - 前后表述是否存在矛盾
  - 前后使用的术语是否一致
- [ ] **论证合理**
  - 论据是否能支持论点
  - 推理过程是否符合逻辑
  - 是否存在逻辑谬误（循环论证、以偏概全等）
- [ ] **无自相矛盾**
  - 同一对象的描述前后一致
  - 时间、数据等信息前后一致
  - 观点、立场前后一致
- [ ] **指代明确**
  - 代词（他、她、它、他们等）指代是否清晰
  - "前者"、"后者"等指代是否明确
  - 是否存在歧义指代
- [ ] **因果关系合理**
  - 因果关系是否有依据
  - 是否存在强加因果
  - 是否存在因果倒置
- [ ] **连词语义一致性** ⭐ 新增
  - 并列连词（与、或、和、及、以及）前后连接的名词应在同一语义层级
  - 错误示例："流感或艰难梭菌" → 正确："流感病毒或艰难梭菌"（均为病原体）
  - 错误示例："手术或药物治疗" → 正确："手术治疗或药物治疗"（均为治疗方法）
  - 错误示例："肺炎和青霉素" → 正确："肺炎和治疗用青霉素"（不应并列不同层级概念）
  - 规则：当连词连接一个简称/缩略语和一个完整术语时，检查两者是否真正可比

## 输出要求

### 简洁原则

**重要**：按照问题类型采用不同的输出策略：

1. **标点符号错误**（句号、逗号、分号、冒号等）：
   - description：简短指出错误，不解释
   - suggestion：直接给出修改
   - 示例：
     ```json
     {
       "current": "血压102/34mmHg",
       "suggested": "血压102/34mmHg",
       "description": "单位符号错误"
     }
     ```

2. **其他错误**（语法、逻辑、表达等）：
   - description：简洁描述问题（1-10个字）
   - reason：简单说明依据（可选）
   - suggestion：给出明确的修改建议
   - 示例：
     ```json
     {
       "current": "通过这次学习，使我认识到...",
       "suggested": "通过这次学习，我认识到...",
       "description": "语序不当",
       "reason": "主谓搭配不当"
     }
     ```

### 具体要求

1. **description字段**：
   - 标点错误：5字以内
   - 单位错误：10字以内
   - 其他错误：15字以内

2. **reason字段**：
   - 标点错误：不填写或填写"标点符号使用规范"
   - 单位错误：不填写或填写"计量单位使用规范"
   - 其他错误：简要说明（1句话，不超过20字）

3. **suggestion字段**：
   - 给出明确、可直接使用的修改建议
   - 避免模糊词汇如"建议检查"、"考虑修改"

4. **避免冗余**：
   - 不要重复current中的完整内容
   - 不要使用"建议将XXX修改为YYY"这种冗长表达
   - 不要对明显错误进行解释（如"句号应改为逗号"）

## 输出格式

```json
{
  "segment_id": "段落编号",
  "page_number": "页码",
  "text": "文本内容",
  "issues": [
    {
      "category": "grammar",
      "severity": "major",
      "location": "具体位置",
      "description": "简洁的问题描述",
      "current": "当前文本",
      "suggested": "建议修改",
      "rule": "相关规范"
    }
  ],
  "statistics": {
    "character_count": "字数",
    "error_count": "错误数",
    "error_rate": "错误率"
  },
  "status": "校对状态"
}
```

## 质量标准

- **优秀**：无语言错误，表达流畅
- **良好**：偶有小问题但不影响理解
- **合格**：有一些问题但整体可读
- **不合格**：多处错误影响阅读

## 不检查范围

以下检查由其他技能负责，本技能不涉及：
- **术语标准性（NHC规范）**：由 medical_term_proofreading 负责
- **术语跨章节一致性**：由 consistency_proofreading 负责
- **临床诊断逻辑**：由 clinical_logic_proofreading 负责
- **翻译准确性**：由 translation_proofreading 负责
- **参考文献格式**：由 reference_proofreading 负责
- **文字润色优化**：由 expression_refinement 负责

## 上角标引用标记

正文中出现的 `<sup>[N]</sup>` 标记是原文中的上角标引用编号。
- **不要**对 `<sup>` 包裹的内容标记括号类型错误（全角/半角）
- **不要**对 `<sup>` 内容标记位置、间距或格式问题
- 标点符号检查应跳过 `<sup>` 标签内部的标点

## 注意事项

1. 医学书籍语言要求准确性高于灵活性
2. 不确定时优先使用学术规范表达
3. 注意保留专业术语的原文
4. 避免过度修改导致风格不统一
5. 语法问题与风格问题需区分对待
