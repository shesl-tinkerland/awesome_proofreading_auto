## 1. 化验值与临床描述一致性

### 1.1 体温与发热描述
- [ ] 体温≥37.3℃时描述为"发热"
- [ ] 体温正常时未错误描述为"发热"
- [ ] 发热程度与体温值对应（低热37.3-38℃ / 中度热38.1-39℃ / 高热39.1-41℃）
- [ ] 体温数值未出现格式错误（如"370℃"应为"37.0℃"）

### 1.2 血常规与描述
- [ ] WBC升高（>10.0×10⁹/L）时描述"白细胞升高/感染"
- [ ] WBC降低（<4.0×10⁹/L）时描述"白细胞减少"
- [ ] Hb男性<120g/L、女性<110g/L时描述"贫血"
- [ ] PLT<100×10⁹/L时描述"血小板减少"

### 1.3 炎症指标与感染描述
- [ ] CRP升高（>8 mg/L）时描述"炎症反应/感染"
- [ ] PCT升高（>0.05 ng/ml）时描述"细菌感染"
- [ ] ESR升高（男>15 mm/h，女>20 mm/h）时描述"炎症/感染"

### 1.4 肝功能与肝损伤描述
- [ ] ALT/AST升高（>40 U/L）时描述"肝功能异常/肝损伤"
- [ ] TBil/DBil升高时描述"黄疸"

### 1.5 肾功能与肾损伤描述
- [ ] Cr升高（男>133，女>106 μmol/L）时描述"肾功能异常"
- [ ] BUN升高（>8.2 mmol/L）时描述"肾功能异常"

### 1.6 心肌标志物与心肌损伤描述
- [ ] cTnI/cTnT升高时描述"心肌损伤"
- [ ] CK-MB升高（>25 U/L）时描述"心肌损伤"
- [ ] BNP/NT-proBNP升高时描述"心衰/心功能不全"

## 2. 数值范围合理性

### 2.1 生命体征
- [ ] 体温在合理范围（正常36.0-37.2℃，不超过42℃）
- [ ] 脉搏在合理范围（正常60-100次/分）
- [ ] 呼吸在合理范围（正常12-20次/分）
- [ ] 收缩压在合理范围（正常90-140 mmHg）
- [ ] 舒张压在合理范围（正常60-90 mmHg）
- [ ] 血氧饱和度在合理范围（正常≥95%）

### 2.2 血常规
- [ ] WBC：(4.0-10.0)×10⁹/L
- [ ] RBC：男(4.0-5.5)×10¹²/L，女(3.5-5.0)×10¹²/L
- [ ] Hb：男120-160g/L，女110-150g/L
- [ ] HCT：男40-50%，女35-45%
- [ ] PLT：(100-300)×10⁹/L
- [ ] 中性粒细胞%：50-70%

### 2.3 生化指标
- [ ] ALT：5-40 U/L
- [ ] AST：5-40 U/L
- [ ] TBil：1.7-21.0 μmol/L
- [ ] DBil：0-6.8 μmol/L
- [ ] ALB：40-55 g/L
- [ ] Cr：男44-133 μmol/L，女70-106 μmol/L
- [ ] BUN：2.9-8.2 mmol/L
- [ ] UA：男208-428 μmol/L，女155-357 μmol/L
- [ ] K：3.5-5.5 mmol/L
- [ ] Na：135-145 mmol/L
- [ ] Cl：96-106 mmol/L
- [ ] GLU（空腹）：3.9-6.1 mmol/L
- [ ] TC：<5.2 mmol/L
- [ ] TG：<1.7 mmol/L

### 2.4 心脏标志物
- [ ] cTnI：<0.04 ng/ml
- [ ] cTnT：<0.1 ng/ml
- [ ] CK-MB：<25 U/L
- [ ] BNP：<100 pg/ml
- [ ] NT-proBNP：<450 pg/ml（<50岁）

### 2.5 炎症指标
- [ ] CRP：<8 mg/L
- [ ] PCT：<0.05 ng/ml
- [ ] ESR：男<15 mm/h，女<20 mm/h

### 2.6 凝血功能
- [ ] PT：11-15秒
- [ ] APTT：25-40秒
- [ ] INR：0.8-1.2
- [ ] FIB：2-4 g/L
- [ ] TT：14-21秒

### 2.7 心脏超声
- [ ] LVEDd：35-56 mm
- [ ] LVEF：≥50%
- [ ] 室间隔厚度：6-11 mm

## 3. 多来源数据交叉验证

### 3.1 化验单 vs 病历描述
- [ ] 化验单数值与病历描述一致
- [ ] 异常值已正确标记（↑↓）

### 3.2 影像学 vs 结论
- [ ] 影像描述与诊断结论一致
- [ ] 影像表现与临床诊断对应

### 3.3 体格检查 vs 辅助检查
- [ ] 心脏杂音与超声发现瓣膜问题对应
- [ ] 肺部啰音与胸片/CT表现对应
- [ ] 腹部压痛与影像学发现对应

### 3.4 诊断 vs 检查结果
- [ ] 感染诊断与WBC/CRP/PCT结果对应
- [ ] 贫血诊断与Hb数值对应
- [ ] 心衰诊断与BNP/NT-proBNP/超声结果对应

### 3.5 治疗 vs 反应
- [ ] 用药后症状改善时间符合药代动力学
- [ ] 抗生素使用后体温变化符合预期

### 4.1 就诊时间线
- [ ] 发病→就诊→检查→诊断→治疗时间顺序合理
- [ ] 各环节间隔时间符合临床常规

### 4.2 检查时间 vs 结果
- [ ] 检查时间与报告时间合理
- [ ] 连续检查的时间间隔合理

### 4.3 治疗 vs 反应时间
- [ ] 抗生素起效时间合理（通常24-72小时）
- [ ] 退热药起效时间合理（通常0.5-2小时）

- [ ] 症状发展速度符合疾病自然病程
- [ ] 并发症出现时间合理

## 5. 相关化验指标一致性

### 5.1 WBC vs 中性粒细胞%
- [ ] WBC升高时，中性粒细胞%通常也升高
- [ ] 二者变化方向匹配

### 5.2 Hb vs RBC vs HCT
- [ ] 贫血时，三者应同时降低
- [ ] 三者变化趋势一致

### 5.3 肝脏指标
- [ ] 肝损伤时，ALT/AST通常同时升高
- [ ] 梗阻性黄疸时，TBil/DBil/ALP/GGT均升高

### 5.4 肾脏指标
- [ ] 肾损伤时，Cr和BUN通常同时升高
- [ ] 二者变化趋势一致

## 常见问题速查
- [ ] 体温正常但描述发热（核对体温与发热描述）
- [ ] WBC正常但描述感染（核对WBC与感染描述）
- [ ] Hb正常但诊断贫血（核对Hb与贫血诊断）
- [ ] 血压正常但诊断高血压（核对血压值与高血压诊断）
- [ ] 抗生素"立即退热"（核对起效时间逻辑）
- [ ] 体温/血压超出生理可能范围（核对数值量级）
- [ ] 同一指标前后数值不一致（核对数据来源）
- [ ] 小数点错误导致数量级偏差（如Cr 8.5 vs 85 μmol/L）
- [ ] 单位标注错误（如mg与μg混淆）
