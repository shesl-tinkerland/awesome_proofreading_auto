# 数据一致性校对技能 (Data Consistency Proofreading Skill)

## 技能描述

专门用于检查医学书籍中的数据一致性问题，包括化验值与临床描述的对应关系、数值范围的合理性、多来源数据的交叉验证、时间序列的逻辑性等。这是医学编辑保证内容科学性和准确性的核心技能。

**核心目标**：确保所有医学数据（化验、影像、体征、诊断等）之间的一致性和逻辑性。

## 校对依据

- 临床检验参考范围标准
- 医学统计学原理
- 临床诊断学标准
- 各专科临床指南
- 循证医学证据

## 校对项目

### 1. 化验值与临床描述一致性检查
- [ ] **体温与发热描述**
  - 体温≥37.3℃时，是否描述为"发热"
  - 体温正常时，是否错误描述为"发热"
  - 发热程度描述（低热/中度热/高热）与体温值对应
  - 参考：低热37.3-38℃，中度热38.1-39℃，高热39.1-41℃

- [ ] **血常规与描述**
  - WBC升高时，是否描述"白细胞升高/感染"
  - WBC降低时，是否描述"白细胞减少"
  - Hb男性<120g/L、女性<110g/L时，是否描述"贫血"
  - PLT<100×10⁹/L时，是否描述"血小板减少"

- [ ] **炎症指标与感染描述**
  - CRP升高时，是否描述"炎症反应/感染"
  - PCT升高时，是否描述"细菌感染"
  - ESR升高时，是否描述"炎症/感染"

- [ ] **肝功能与肝损伤描述**
  - ALT/AST升高时，是否描述"肝功能异常/肝损伤"
  - TBil/DBil升高时，是否描述"黄疸"

- [ ] **肾功能与肾损伤描述**
  - Cr升高时，是否描述"肾功能异常"
  - BUN升高时，是否描述"肾功能异常"

- [ ] **心肌酶与心肌损伤描述**
  - cTnI/cTnT升高时，是否描述"心肌损伤"
  - CK-MB升高时，是否描述"心肌损伤"

- [ ] **BNP/NT-proBNP与心衰描述**
  - BNP/NT-proBNP升高时，是否描述"心衰/心功能不全"

### 2. 数值范围合理性检查
- [ ] **生命体征范围**
  - 体温：36.0-37.2℃（正常）
  - 脉搏：60-100次/分
  - 呼吸：12-20次/分
  - 收缩压：90-140 mmHg
  - 舒张压：60-90 mmHg

- [ ] **血常规范围**
  - WBC：(4.0-10.0)×10⁹/L
  - RBC：男性(4.0-5.5)×10¹²/L，女性(3.5-5.0)×10¹²/L
  - Hb：男性120-160g/L，女性110-150g/L
  - PLT：(100-300)×10⁹/L
  - 中性粒细胞%：50-70%

- [ ] **生化指标范围**
  - ALT：5-40 U/L
  - AST：5-40 U/L
  - TBil：1.7-21.0 μmol/L
  - Cr：男性44-133 μmol/L，女性70-106 μmol/L
  - K：3.5-5.5 mmol/L
  - Na：135-145 mmol/L

- [ ] **心脏超声范围**
  - LVEDd：35-56 mm
  - LVEF：≥50%
  - 室间隔厚度：6-11 mm

### 3. 多来源数据交叉验证
- [ ] **化验单 vs 病历描述**
  - 化验单数值与病历描述是否一致
  - 异常值是否被标记（↑↓）

- [ ] **影像学 vs 结论**
  - 影像描述与诊断结论是否一致
  - 影像表现与临床诊断是否对应

- [ ] **体格检查 vs 辅助检查**
  - 心脏杂音 vs 超声发现瓣膜问题
  - 肺部啰音 vs 胸片/CT表现
  - 腹部压痛 vs 影像学发现

- [ ] **诊断 vs 检查结果**
  - 感染诊断 vs WBC/CRP/PCT
  - 贫血诊断 vs Hb
  - 心衰诊断 vs BNP/NT-proBNP/超声

- [ ] **治疗 vs 反应**
  - 用药后症状改善时间是否符合药代动力学
  - 抗生素使用后体温变化是否符合预期

### 4. 时间序列逻辑性检查
- [ ] **就诊时间线**
  - 发病→就诊→检查→诊断→治疗的时间顺序合理
  - 各环节间隔时间符合临床常规

- [ ] **检查时间 vs 结果**
  - 检查时间与报告时间合理
  - 连续检查的时间间隔合理

- [ ] **治疗 vs 反应时间**
  - 抗生素起效时间（通常24-72小时）
  - 退热药起效时间（通常0.5-2小时）
  - 激素起效时间（通常数小时到数天）

- [ ] **病情发展时间**
  - 症状发展速度符合疾病自然病程
  - 并发症出现时间合理

### 5. 相关化验指标一致性检查
- [ ] **WBC vs 中性粒细胞%**
  - WBC升高时，中性粒细胞%通常也升高
  - 核对二者是否匹配

- [ ] **Hb vs RBC vs HCT**
  - 贫血时，三者应同时降低
  - 核对三者是否一致

- [ ] **肝脏指标**
  - 肝损伤时，ALT/AST通常同时升高
  - 梗阻性黄疸时，TBil/DBil/ALP/GGT均升高

- [ ] **肾脏指标**
  - 肾损伤时，Cr和BUN通常同时升高
  - 核对二者是否一致

### 6. 数值计算准确性检查
- [ ] **平均值计算**
  - 计算是否正确

- [ ] **百分比计算**
  - 百分比计算是否正确

- [ ] **单位换算**
  - mg与g换算
  - mmol/L与mg/dl换算

## 常见数据一致性问题

### 1. 化验值与描述不符
| 问题描述 | 示例 | 问题分析 |
|---------|------|---------|
| 体温正常但描述发热 | 体温36.5℃，描述"患者发热" | 数据与描述矛盾 |
| WBC正常但描述感染 | WBC 6.5×10⁹/L，描述"白细胞升高" | 数值在正常范围 |
| Hb正常但诊断贫血 | Hb 130g/L，诊断"贫血" | 未达到贫血标准 |
| 血压正常但诊断高血压 | 血压120/80mmHg，诊断"高血压" | 数值在正常范围 |

### 2. 相关指标不一致
| 问题描述 | 示例 | 问题分析 |
|---------|------|---------|
| WBC升高但N%正常 | WBC 15×10⁹/L↑，N% 45% | 通常应同时升高 |
| Hb降低但RBC正常 | Hb 80g/L↓，RBC 5.0×10¹²/L | 贫血时RBC应降低 |
| 肝功能ALT升高AST正常 | 诊断"肝损伤"，ALT 200U/L↑，AST正常 | 通常ALT/AST同时升高 |
| 感染诊断但炎症指标正常 | 诊断"严重感染"，CRP 5mg/L，PCT 0.05ng/ml | 感染时炎症指标应升高 |

### 3. 时间逻辑混乱
| 问题描述 | 示例 | 问题分析 |
|---------|------|---------|
| 治疗起效过快 | "抗生素使用后立即退热" | 抗生素通常需数小时起效 |
| 时间顺序混乱 | "治疗后检查，发现异常，然后开始治疗" | 时间顺序不合理 |
| 检查时间冲突 | "3月8日检查结果为3月10日的检查" | 时间错误 |

### 4. 单位或数值错误
| 问题描述 | 示例 | 问题分析 |
|---------|------|---------|
| 单位错误 | "体温370℃" | 应为37.0℃ |
| 数值超范围 | "收缩压300mmHg" | 超出生理可能范围 |
| 小数点错误 | "Cr 8.5μmol/L" | 应为85μmol/L |

### 5. 前后数据不一致
| 问题描述 | 示例 | 问题分析 |
|---------|------|---------|
| 同一指标数值不同 | 前文Hb 80g/L，后文Hb 120g/L | 核实原始数据 |
| 诊断前后矛盾 | 前文诊断"感染"，后文诊断"非感染" | 检查诊断准确性 |

## 优先级说明

### critical（严重）
- **关键化验值与诊断严重不符**：可能误导临床判断
- **生命体征数值异常**：超出生理可能范围
- **治疗与反应严重不符**：可能影响临床决策
- **时间逻辑严重混乱**：导致内容无法理解

### major（重要）
- **非关键化验值与描述不符**：需要核实
- **相关指标轻微不一致**：可能提示数据问题
- **部分时间顺序不合理**：但不影响整体理解

### minor（轻微）
- **非核心数据的小问题**：不影响整体准确性
- **单位格式不统一**：但不影响数值准确性
- **描述不够精确**：但数据本身正确

## 各系统重点检查项目

### 心血管系统
- 血压与高血压诊断
- 心率与心电图
- 心肌酶与心肌梗死诊断
- BNP/NT-proBNP与心衰诊断
- 超声LVEF与心功能分级
- 超声瓣膜异常与杂音

### 呼吸系统
- 血气分析与呼吸状态
- 胸片/CT与肺炎诊断
- 炎症指标与感染程度
- 血氧饱和度与呼吸功能

### 消化系统
- 肝功能与肝损伤诊断
- 腹部影像与诊断
- 内镜发现与病理结果
- 黄疸指标与描述

### 肾脏系统
- 肾功能与肾损伤诊断
- 尿检与肾脏疾病
- 电解质与肾功能
- 肾脏影像与诊断

### 内分泌系统
- 血糖与糖尿病诊断
- 甲状腺功能与甲亢/甲减
- 激素水平与内分泌疾病
- 糖化血红蛋白与血糖控制

## 输出要求

### 简洁原则

1. **化验值与描述不符**：
   - description：5字以内
   - suggestion：指出矛盾点
   - reason：说明正常关系（15字以内）

2. **数值超范围**：
   - description：10字以内
   - suggestion：指出合理范围或核实数值
   - reason：说明正常范围

3. **指标不一致**：
   - description：10字以内
   - suggestion：指出不一致的指标
   - reason：说明指标间正常关系

4. **时间逻辑问题**：
   - description：10字以内
   - suggestion：指出时间逻辑错误
   - reason：说明合理时序

## 不检查范围

以下检查由其他技能负责，本技能不涉及：
- **临床诊断逻辑**：由 clinical_logic_proofreading 负责
- **术语标准性**：由 medical_term_proofreading 负责
- **语言语法和标点**：由 language_proofreading 负责
- **表格数据准确性**：由 table_proofreading 负责

## 注意事项

1. **参考范围可能因实验室而异**：需以具体实验室参考为准
2. **个体差异存在**：异常值不一定都是错误
3. **特殊情况**：某些疾病可能导致指标不典型变化
4. **核实数据来源**：不确定时应标注，而非主观判断
5. **保持客观**：基于数据，不猜测原因
6. **关注患者安全**：可能影响临床决策的问题必须指出

## 质量标准

- **优秀**：无数据一致性问题，所有数据准确
- **良好**：偶有轻微问题但不影响整体
- **合格**：有一些问题但核心数据正确
- **不合格**：存在严重数据矛盾或错误
