# 表格校对技能 (Table Proofreading Skill)

## 技能描述

专门用于校对医学书籍中的表格内容，包括表格格式、数据准确性、表头规范、跨页处理等各方面的问题检测。

## 校对项目

### 1. 表格编号检查
- [ ] 表格编号是否连续（表1-1、表1-2...）
- [ ] 编号格式是否符合规范
- [ ] 正文引用与表格编号是否对应
- [ ] 跨章节表格编号是否正确处理

### 2. 表头检查
- [ ] 表头是否完整
- [ ] 表头翻译是否准确
- [ ] 列名含义清晰
- [ ] 单位是否标注
- [ ] 缩写是否有说明
- [ ] 表头层级是否清晰（多层表头）

### 3. 数据准确性检查
- [ ] 数据与正文描述一致
- [ ] 计算结果正确（合计、百分比等）
- [ ] 数值范围合理
- [ ] 数据格式统一
- [ ] 缺失数据标注（—、N/A等）

### 4. 表格格式检查
- [ ] 对齐方式正确（文字左对齐、数字右对齐/小数点对齐）
- [ ] 列宽合理
- [ ] 边框线条规范
- [ ] 字体大小一致
- [ ] 行距、间距统一

### 5. 跨页表格检查
- [ ] 跨页表格表头是否重复
- [ ] 跨页标注是否正确（续表）
- [ ] 页面断开位置合理（不在数据行中间）
- [ ] 跨页后数据连续性

### 6. 表注检查
- [ ] 表注完整（表题、表注）
- [ ] 表题翻译准确
- [ ] 表注说明清晰
- [ ] 脚注编号与表中标示一致
- [ ] 统计学标注正确（*、**、†等）

### 7. 特殊类型表格
- [ ] **统计表**：P值、置信区间、标准差格式
- [ ] **对比表**：基准明确、对比项目对齐
- [ ] **分类表**：分类标准清晰、不重复不遗漏
- [ ] **流程表**：步骤连续、逻辑清晰
- [ ] **汇总表**：数据来源标注、统计方法说明

### 8. 单位和符号检查
- [ ] 单位符号规范（SI单位）
- [ ] 单位标注位置正确（列标题中）
- [ ] 百分比符号使用一致
- [ ] 特殊符号正确（±、≈、≤、≥等）

### 9. 一致性检查
- [ ] 同一指标在不同表格中名称一致
- [ ] 同类数据格式一致
- [ ] 缩写使用一致
- [ ] 数据精度一致

## 输出格式

```json
{
  "issues": [
    {
      "table_id": "表1-1",
      "category": "问题类别",
      "severity": "严重程度",
      "location": "P{段落编号}",
      "description": "问题描述",
      "current": "原文内容",
      "suggested": "修改建议"
    }
  ]
}
```

## 常见问题类型

| 问题类别 | 严重程度 | 示例 |
|---------|---------|------|
| 数据错误 | 严重 | 合计值计算错误 |
| 表头缺失 | 严重 | 缺少列名或单位 |
| 格式混乱 | 一般 | 对齐错误、列宽不当 |
| 翻译问题 | 一般 | 表头翻译不准确 |
| 跨页问题 | 轻微 | 表头未重复 |

## 质量标准

- **无问题**：表格完全符合要求
- **轻微问题**：格式、样式等不影响理解的问题
- **一般问题**：对齐、标注等问题
- **严重问题**：数据错误、表头错误等需重新制作

## 不检查范围

以下检查由其他技能负责，本技能不涉及：
- **数据临床合理性**：由 clinical_logic_proofreading 负责
- **术语标准性**：由 medical_term_proofreading 负责
- **语言语法和标点**：由 language_proofreading 负责

## 注意事项

1. 医学数据表格的准确性至关重要
2. 统计学表格需要专业统计人员审核
3. 注意区分原始数据和统计数据
4. 跨页表格需特别检查数据连续性
5. 表格应尽可能自明（不依赖正文说明）
