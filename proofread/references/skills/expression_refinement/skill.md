# 表达润色技能 (Expression Refinement Skill)

## 技能描述

对文档做**字词级**的润色优化，核心目标不是"找错"，而是"让每个字恰到好处"。检查用词精准度、消除隐蔽冗余、优化固定搭配、统一语体风格、避免近距离重复。

**定位**：与其他校对技能互补。其他技能回答"这里有什么错"，本技能回答"这里能不能更好"。

## 与语言校对的区别

| 维度 | language_proofreading | expression_refinement |
|------|----------------------|-----------------------|
| 核心问题 | "这句话对不对？" | "这句话好不好？" |
| 检查粒度 | 句子级 | 字词级 |
| 典型发现 | 句式杂糅、标点错误 | 冗余虚词、搭配不当、用词可更精准 |
| 修改性质 | 改错 | 优化 |
| 严重程度 | critical/major为主 | minor为主 |

## 校对依据

- 《现代汉语词典》搭配惯例
- 《科技书刊标准化用法》
- 出版行业"三校一读"中的"一读"通读润色标准

## 校对项目（5项）

### 1. 用词精准度

检查每个实词（名词、动词、形容词）是否是当前语境下的最佳选择。

- [ ] 近义词辨析：多个近义词均可使用时，是否选了最精准的一个
- [ ] 感情色彩匹配：词的感情色彩（褒/贬/中）是否与上下文一致
- [ ] 语义强度适配：词的语义强度是否与语境匹配（如"预防"vs"缓冲"）
- [ ] 具体vs抽象：科普文体中是否使用了过于抽象的词，可用更具体的词替代

**示例**：
| 原文 | 润色 | 理由 |
|------|------|------|
| "获得了幸福感" | "拥有了幸福感" | "获得"强调获取动作，"拥有"强调持续状态，与"持续"搭配更好 |
| "预防头部损伤后遗症" | "缓冲头部损伤的影响" | 认知储备是缓冲而非预防 |
| "差异" | "差距" | "缩小"应搭配"差距"而非"差异" |

### 2. 隐蔽冗余消除

检查句子中每个虚词（助词、介词、连词、能愿动词）是否有实际语义贡献。无贡献的应删除。

- [ ] 冗余介词："在...中"、"通过...使"结构中的多余介词
- [ ] 冗余助词："所+动词+的"中的"所"是否必要
- [ ] 冗余能愿动词："能发挥作用"中的"能"是否与上下文重复
- [ ] 冗余连词：两个分句间的连词是否与关联词重复
- [ ] 冗余修饰语：修饰语是否已暗含在中心词中

**示例**：
| 原文 | 润色 | 理由 |
|------|------|------|
| "在作者的一项研究中发现" | "作者的一项研究发现" | 冗余介词"在" |
| "策略所培养的心理韧性" | "策略培养的心理韧性" | 冗余助词"所" |
| "能让我们能更从容" | "使我们更从容" | 冗余能愿动词，且"让...能"重复 |
| "既能抵御...又能有效预防" | "既能抵御...又能预防" | "有效"已被"能"包含 |

### 3. 搭配优化

检查固定搭配、动宾搭配、量词搭配是否符合中文习惯。

- [ ] 动宾搭配：动词与宾语的搭配是否为惯用搭配
- [ ] 修饰搭配：形容词/副词与中心词的搭配是否自然
- [ ] 量词搭配：量词与名词的搭配是否规范
- [ ] 介宾搭配：介词与宾语的搭配是否符合中文习惯
- [ ] **主谓搭配** ⭐ 新增：主语与谓语在语义上是否匹配
  - 错误示例："严重程度是一个连续的光谱" → 正确："严重程度呈连续性"（"是...光谱"搭配不当）
  - 错误示例："风险升高了一个台阶" → 正确："风险显著升高"（医学文体避免比喻性搭配）

**示例**：
| 原文 | 润色 | 理由 |
|------|------|------|
| "筑起防护墙" | "筑起一道防护墙" | 缺量词 |
| "缩小断层" | "缩小差距" | "缩小"的固定搭配是"差距" |
| "重视...重要性" | "重视...程度" | "重视"搭配"程度"更自然 |
| "严重程度是一个连续的光谱" | "严重程度呈连续性" | 主谓搭配不当，"光谱"不适合描述严重程度 |

### 4. 语体统一

检查全文的人称、正式度、表述风格是否前后一致。

- [ ] 人称统一：全文是否统一使用同一人称体系（"我们"/"人们"/"读者"不混用）
- [ ] 正式度统一：同一文档中的正式程度是否一致（学术vs科普不突兀切换）
- [ ] 称呼统一：对同一对象的称呼是否全文一致

**示例**：
| 原文 | 润色 | 理由 |
|------|------|------|
| "帮助我们发现...帮助我们判断" | "帮助人们发现...帮助人们判断" | 科普书不宜用"我们"，应统一为"人们" |
| "助你实现...助力你走向" | "帮助读者实现...助力读者走向" | 科普书统一用"读者"更正式 |
| "认知能力"...三段后..."认知功能" | 全文统一 | 同一概念应用同一表述 |

### 5. 近距离重复检测

检查同一段落或相邻段落中是否有不必要的用词重复或句式重复。

- [ ] 同词重复：同一段落中同一个实词出现2次以上，是否可用近义词替换
- [ ] 句式重复：相邻句子是否使用了相同的句式结构
- [ ] 举例重复："例如"连续出现时，第二个改为"又如"或"再如"

**示例**：
| 原文 | 润色 | 理由 |
|------|------|------|
| "例如规划能力...例如，回忆" | "例如规划能力...又如回忆" | 连续两个"例如"，第二个改为"又如" |
| "解决问题时...成功解决问题" | "解决问题时...成功破解难题" | 同段重复"解决问题" |

## 严重程度判定

本技能的特殊判定规则：润色建议以 minor 为主，仅以下情况标为 major：

| 级别 | 判定标准 | 示例 |
|------|---------|------|
| major | 冗余导致语义重复或理解困难 | "通过...使..."双重介词导致主语缺失 |
| major | 语体突然切换影响阅读体验 | 学术段中突然出现口语化"你" |
| minor | 用词可更精准但原文不错 | "获得"可改为"拥有" |
| minor | 隐蔽冗余可删但不影响理解 | "所培养的"可删"所" |
| minor | 搭配可优化但原文可接受 | "缩小断层"可改为"缩小差距" |

## 输出格式

```json
{
  "skill_name": "expression_refinement",
  "segment_id": "P起始-P结束",
  "page_number": "页码",
  "issues": [
    {
      "category": "refinement",
      "severity": "minor",
      "issue_type": "word_precision|redundancy|collocation|register|repetition",
      "location": "P段落号",
      "description": "简短描述（5-10字）",
      "current": "当前文本（精确定位到具体字词）",
      "suggested": "建议修改",
      "reason": "修改依据（≤15字）"
    }
  ],
  "summary": {
    "total_issues": 0,
    "critical_count": 0,
    "major_count": 0,
    "minor_count": 0
  },
  "status": "pass/warning"
}
```

### issue_type 取值

| issue_type | 说明 |
|-----------|------|
| `word_precision` | 用词精准度 |
| `redundancy` | 隐蔽冗余 |
| `collocation` | 搭配优化 |
| `register` | 语体统一 |
| `repetition` | 近距离重复 |

## 质量标准

- **宁可漏检，不可误报**：润色建议必须是明确的改善，不是个人偏好
- **改一处只说一处**：不要把多个微调合并为一条建议
- **保持原文风格**：不改变作者的表达意图和文体风格
- **科普文体适配**：科普书允许适度的口语化，不要过度学术化

## 不检查范围

以下检查由其他技能负责，本技能不涉及：
- **语法正确性**：由 language_proofreading 负责
- **术语标准性**：由 medical_term_proofreading 负责
- **翻译准确性**：由 translation_proofreading 负责
- **临床逻辑**：由 clinical_logic_proofreading 负责
- **参考文献格式**：由 reference_proofreading 负责

## 注意事项

1. 本技能不检查语法错误（由 language_proofreading 负责）
2. 本技能不检查标点、数字、格式（由 language_proofreading 负责）
3. 本技能不检查术语准确性（由 medical_term_proofreading 负责）
4. 本技能不检查翻译质量（由 translation_proofreading 负责）
5. 润色建议如与原文作者风格冲突，标注为 minor 并在 reason 中说明"视风格偏好决定"
