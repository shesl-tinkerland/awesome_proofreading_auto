# 表达润色检查清单

逐句检查，对每个有改善空间的词标记建议。

## 用词精准度
- [ ] 每个动词是否是当前语境最佳选择
- [ ] 近义词中是否选了最精准的（差异vs差距、获得vs拥有、预防vs缓冲）
- [ ] 感情色彩是否与上下文一致
- [ ] 语义强度是否适配

## 隐蔽冗余
- [ ] "在...中/上/里"中的"在"是否必要
- [ ] "通过...使..."是否双重介词
- [ ] "所+动词+的"中的"所"是否必要
- [ ] "能/可以+动词"中的能愿动词是否冗余
- [ ] 修饰语是否已暗含在中心词中

## 搭配优化
- [ ] 动宾搭配是否惯用
- [ ] "缩小/扩大/增加"后的名词是否为固定搭配
- [ ] 量词是否完整（"筑起防护墙"缺"一道"）
- [ ] "重视/关注/强调"后的搭配是否恰当

## 语体统一
- [ ] 全文人称是否统一（我们/人们/读者/你）
- [ ] 全文正式度是否一致
- [ ] 对同一对象的称呼是否统一

## 近距离重复
- [ ] 同段内同一实词是否出现2次以上
- [ ] 连续"例如"是否可替换第二个为"又如"
- [ ] 相邻句子是否句式雷同
