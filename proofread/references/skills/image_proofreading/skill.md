# 图片校对技能 (Image Proofreading Skill)

## 技能描述

专门用于校对医学书籍中的图片内容，包括图片质量、标注、编号、图注等各方面的问题检测。

## 校对项目

### 1. 图片编号检查
- [ ] 图片编号是否连续（图1-1、图1-2...）
- [ ] 编号格式是否符合规范
- [ ] 正文引用与图片编号是否对应
- [ ] 跨章节图片编号是否正确处理

### 2. 图片质量检查
- [ ] 图片清晰度是否足够
- [ ] 图片是否有变形、拉伸
- [ ] 色彩是否准确（医学影像图）
- [ ] 图片裁剪是否恰当
- [ ] 分辨率是否达到印刷要求（≥300dpi）

### 3. 图注检查
- [ ] 图注是否完整
- [ ] 图注翻译是否准确
- [ ] 专业术语翻译是否规范
- [ ] 图注格式是否符合要求
- [ ] 图中标注说明是否与图注一致

### 4. 图片内容检查
- [ ] 图片内容是否与正文描述一致
- [ ] 医学解剖图是否准确
- [ ] 数据图表是否清晰可读
- [ ] 图片方向是否正确
- [ ] 图片是否有版权标注

### 5. 标注元素检查
- [ ] 图中箭头、标注线是否清晰
- [ ] 标注文字是否准确
- [ ] 缩写是否在图注中说明
- [ ] 单位是否标注
- [ ] 图例是否完整

### 6. 特殊类型图片
- [ ] **显微镜图片**：放大倍数标注
- [ ] **影像学图片**：检查窗宽窗位、拍摄角度
- [ ] **统计图表**：坐标轴、刻度、图例
- [ ] **流程图**：逻辑关系、箭头方向
- [ ] **解剖图**：结构标注准确性

## 输出格式

```json
{
  "issues": [
    {
      "image_id": "图1-1",
      "category": "问题类别（编号/质量/图注/内容/标注）",
      "severity": "严重程度（critical/major/minor）",
      "location": "P{段落编号}",
      "description": "问题描述",
      "current": "原文内容",
      "suggested": "建议修改"
    }
  ]
}
```

## 检查清单模板

```
□ 图片编号规范检查
□ 图片质量评估
□ 图注翻译准确性
□ 图片内容与正文一致性
□ 标注元素完整性
□ 特殊要求（根据图片类型）
```

## 不检查范围

以下检查由其他技能负责，本技能不涉及：
- **数据临床合理性**：由 clinical_logic_proofreading 负责
- **术语标准性**：由 medical_term_proofreading 负责
- **语言语法和标点**：由 language_proofreading 负责

## 注意事项

1. 医学图片的准确性至关重要，任何内容错误都可能导致严重后果
2. 影像学图片需要专业医师审核
3. 数据图表需要核对原始数据
4. 注意图片的版权和来源标注

## 质量标准

- **无问题**：图片完全符合要求
- **轻微问题**：样式、位置等不影响理解的问题
- **一般问题**：标注、格式等问题
- **严重问题**：内容错误、质量问题需重新制作
